# FlowLoad

**A cleaner way to manage your media workflow.**

FlowLoad is a local-first media workflow application designed to help creators download, import, organize, convert, and export media through a clean and organized desktop experience.

Instead of switching between multiple tools for everyday media tasks, FlowLoad brings essential media workflows together in one place.

## ✨ Features

- **Media Downloads:** Download media from supported sources.
- **Media Converter:** Convert media between supported audio and video formats.
- **Media Library:** Keep your media files organized and accessible.
- **Local-First:** Designed around local media management and user control.
- **Batch Processing:** Handle multiple media tasks through an organized workflow.
- **Clean Interface:** Focus on essential tools without unnecessary complexity.

## 🔄 Workflow

FlowLoad follows a straightforward workflow:

**Source → Download / Import → Manage → Convert → Export**

Each stage is designed to make media handling more organized and efficient.

## 🧩 Workspaces

FlowLoad is organized into three main workspaces:

| Workspace | Purpose |
|---|---|
| Downloads | Manage media downloads and imported content. |
| Media Converter | Convert media into supported formats. |
| Library | Organize and access your media collection. |

- Windows desktop application.
- Designed for local media workflows.
